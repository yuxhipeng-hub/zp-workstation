# 测试局部规则

测试是交付证据，不是通过门禁的装饰。

- 修 bug 先补失败用例再改实现；新行为优先补最接近边界的单元测试，必要时再加 Electron E2E。
- 单元测试使用 Node 内置 test runner，文件名与被测模块对应。外部网络、时钟、文件系统和模型
  调用要注入或 mock，不访问真实服务，不写入用户目录。
- 临时工作区、下载目录和测试数据放在系统临时目录，测试结束清理；不要读取或修改
  `%APPDATA%` 下的真实用户数据。
- 不放宽、跳过或删除失败断言来“修复”测试。确实需要改契约时，先说明行为变化并补回归覆盖。
- Electron E2E 在 Windows 桌面会话运行；若环境带有 `ELECTRON_RUN_AS_NODE=1`，先清除该变量。
  测试失败要保留证据，不能把未执行、超时或人工未看的场景写成通过。
