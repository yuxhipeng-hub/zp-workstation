# 视频制作使用说明

入口：「工具 → 创作工作室 → 新建/选择项目 → 视频制作 → 启用视频制作流程」。
旧项目可继续手动导入、关联目录与版本审片，不启用时不创建制作任务。
默认点七个步骤浏览细分内容树，展开叶节点查看正文与实际媒体；节点旁的铅笔进入手动编辑，返回后保留展开状态。
完整制作工具仍在视频行的工具图标中；日常沟通和修改可继续在Codex主窗口完成。

## 第一个项目

1. 填写创意、受众、场景、目标时长、画幅、画风、声音/字幕要求、参考说明与保留/禁止项。
2. 在 Codex 主对话框沟通创作意图，在工作室核对并保存故事与分镜；修改故事后明确确认故事。
   页面不再内嵌导演聊天入口，历史会话记录保留。
3. 在「分镜与提示词」编辑独立镜头，新增、删除、排序或拆分。镜头包含时长、景别、机位、动作因果、
   左右位置、配色、角色道具数量、衔接和风险。先解决叙事问题再批量制作素材。
   删除重排镜头起点并清理对应剪辑引用，保留媒体、历史、账本与旧成片；活动制作任务结束后才允许删除。
4. 用原「导入产物」选择少量画风样图、角色设定和首尾帧。设定记录保存稳定角色/场景/道具 ID，
   记录服装、配件、左右特征和表情，关联样图后确认设定。绑定具体图片版本；支持并排、叠加、差异辅助与放大，旧文件保留。
5. 在分镜步骤填写七段视频提示词，再到独立审核步骤连接 Codex 并发起审核。审核只接收当前所需材料，
   不带制作自评；无法判断不算通过。修改依赖后审核失效，必须重新审核。
6. 在供应商配置中安全保存方舟 Key、填写模型/接入点 ID、能力档案、输出参数、
   视频生成总预算、每秒费用估算及依据日期、保守预留系数。
7. 点击「检查本次提交」查看实际图片路径/摘要、提示词、模型、时长与费用，再确认系统弹窗。
   没有弹窗确认不会提交。程序执行预算与并发检查，Agent 不能扩大授权。
8. 已知任务自动查询；也可手动「查询与下载」。只有真实下载并探测的 MP4 才登记为已生成。
9. 在「后期与交付」选择具体视频版本、入出点、音量/静音、淡入淡出、字幕、亮度与饱和度，
   保存编辑决定后导出。调整单镜素材后保存并重新导出，旧成片保留。
10. 「作品与版本」播放成片、版本比较与定位意见，人工观看和试听后确认验收；
    原发布复盘继续记录，不自动发布社交平台。

## 连接 Codex

独立审核或后期步骤中，展开「审核模型与记录」连接并选择模型。

使用官方 app-server stdio，由主进程启动和关闭。登录沿用 Codex 本地账户，请先运行 `codex login`。
运行时必须支持 `--disable view_image`；本轮验证版本为 0.167.0，旧 0.144.6 不满足隔离要求。
本机已隔离安装到 `%LOCALAPPDATA%\ZP Workbench\tools\codex`，不修改原全局 CLI 和配置。
其他机器可安装同一路径的官方 npm 包，或把兼容原生 Codex 程序放入 PATH：

```powershell
npm install --prefix "$env:LOCALAPPDATA/ZP Workbench/tools/codex" @openai/codex@0.167.0
```

先读取账号/模型列表，再选择实际模型。旧 CLI 的全局默认曾返回当前账户不支持的模型；
连接成功不能证明任意模型可调用。未登录、协议不兼容、断连和模型错误分别保留提示与已有消息。
独立审核始终新会话；运行结束后刷新制作状态，在「审核模型与记录」查看结果。

子进程移除桌面工具桥环境，关闭 shell、code-mode host、view_image、apps/plugins、
生图、多 Agent、记忆、hooks 和 Web 搜索；在内存读取配置中 MCP 名称后逐一禁用。
明确图片通过 `localImage` 输入。服务端权限/工具请求默认拒绝，没有任意命令 IPC。
模型负责制作决定，FFmpeg 由程序按白名单参数执行；不声称 cwd 或只读策略能单独提供范围隔离。

## 生图与计费

当前接入**没有验证可用的 Codex 生图与稳定图片文件返回**，客户端主动关闭该工具。
本版可用路径是外部生成后手动导入或显式关联目录，图像编辑也在外部工具完成。
生图适配器与导演接口分离；未来可替换为经验证的真实图片服务，需另行配置、计费和授权。
不会把文字、色块草图或模拟服务当真实生成图片。

方舟 Key 用现有 `AiSecretStore` / Electron safeStorage 加密，仅主进程读取；
不进入项目、日志、工作区、备份、镜像和导出。页面输入密码不保留草稿。

预算目前只覆盖本项目的 Seedance 视频生成。Codex 额度/API 费、外部生图、音乐、存储等另计，
未配置的费用不显示为零。官方按实际 token 用量和单价结算；每秒价格由用户根据当前模型估算，
程序按估算×预留系数保留预算，**预留不是供应商最终账单上界**。
可见总额、已结算、处理中及未结算预留、可提交余额。第一版始终逐次确认，不启用预算内自动提交。
成功、失败或过期任务最终费用未知时继续占用预留；核对控制台账单后手动结算，允许真实账单超过预留。
明确的参数/凭证拒绝显示安全错误；网络超时等提交结果不明禁止自动重提。

## 中断、恢复与重做

- 「中断本地任务」请求中断 Codex，终止后期并停止本地轮询。供应商可能继续运行计费。
- 供应商DELETE同时可能删除已完成任务，查询与取消间存在竞态；本版不发送DELETE，
  取消操作请在供应商控制台核查。本地停止不会取消供应商任务。
- 重新打开应用：运行中的本地任务记为中断；已知供应商 ID 先查询，绝不重新 POST。
- 未知提交：先在控制台核查，补录 task ID 后查询下载；不要直接再次生成。
  只有确认未创建任务，才点击核查释放操作并确认系统弹窗。
- 查询或下载失败可重试，复用 task ID，部分文件保留；下载完成后才登记媒体版本。
- 修改一镜后，它及受相邻衔接影响的审核失效；旧片段仍可审片，选新版本再合成。
- 导出失败/中断保留已有成片、源素材与处理目录，原文件不覆盖。

## 数据位置与自动检查

制作记录、版本、会话 ID、供应商 ID、账本和编辑决定在现有 `workspace.json.creationProjects[].video`，
沿用 WorkspaceStore 备份与原子保存。每项目记录最多 3 MB，各类记录最多500条，不静默截掉新版本。
媒体和输出在 `%APPDATA%\deepseek-harness-launcher\creation-video\项目ID\`；
生成片段使用逻辑任务ID文件名，导出使用独立运行目录，含片段、字幕、抽帧和成片。
工作区备份只保存索引，媒体请单独备份。原 `workbench-record.json` 仍为只读协议1，
不执行其中的 command/env 等字段。

FFmpeg 导出全量解码，核对时长、尺寸、帧率、音轨，检测黑帧并在各镜开头/中间/结尾抽帧，
报告定位秒数和帧号。保留来源尺寸与是否放大；放大不恢复原生细节。
未自动判断所有缺镜、突跳、人物畸变、叙事一致性、音乐/对白质量和审美；必须人工观看与试听。
静态画面和有意黑场需人工解释。支持导入MP3/WAV/M4A音轨，混合或替换镜头原音，设置入点、音量和淡入淡出；
不提供复杂时间线或任意模型生成脚本。成片抽帧拼图登记为独立图片版本，可用新Codex会话独立复核，
每张拼图附带镜头、秒数和帧号；未抽到的帧与声音不能声称已检。
