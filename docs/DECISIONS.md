## 记录

### 2026-09-23 课表数据写入走应用代码路径

- 背景：需要把外部 Excel 课表里的课程并入用户现有课表，直接编辑
  `workspace.json` 容易破坏结构或漏掉课程库关联。
- 决定：用 Node 加载 `WorkspaceStore` 与 `ScheduleManager`，调用 `createCourse()` 写入，
  写入前做手工备份，并保留应用的自动备份。
- 代价 / 放弃的方案：不采用脚本直接改 JSON 的方式；需要在写入前确认目标应用是否在运行，
  否则运行中的进程可能用内存旧数据覆盖文件。

### 2026-09-23 修正 DeepSeek 上下文窗口

- 背景：Codex 模型目录里 `deepseek-flash` 声明为 272K 上下文，实际模型支持 1M，
  导致压缩过早、反复丢上下文。
- 决定：把模型目录的 `context_window` / `max_context_window` 改为 1048576，
  `auto_compact_token_limit` 设为 800000，并在 `config.toml` 中写入同样的值。
- 代价 / 放弃的方案：长线程每轮输入更大，缓存未命中时单次成本更高，
  因此配套要求保持提示词前缀稳定、按功能切线程。
