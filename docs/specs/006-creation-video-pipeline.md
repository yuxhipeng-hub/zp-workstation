# 创作工作室：视频制作流程

本轮在原工作室上增加可选择启用的视频流程。旧项目、快照、备份、外部协议 1 和人工验收保持兼容。
基线 be7f228；不修改 Agent 配置，不执行远端操作，不自动提交付费测试。

## 实施顺序与验收

1. 核对官方协议与本机 Codex/FFmpeg，记录能力实测；X 原文访问受 403 限制，以用户完整需求为实施依据。
2. 可选 video 数据、不可变内容版本、稳定镜头身份、素材绑定、依赖摘要和隔离审核。
3. 主进程 Codex stdio 客户端；持续会话、事件、恢复、中断。模型只产出结构化制作决定，后期由受控 FFmpeg 执行。
4. 独立 Seedance 适配器、明确请求预览、单次确认、原子预算预留、未知提交封锁和已知任务恢复下载。
5. 原生制作工作区：简报、故事确认、分镜、设定/首尾帧、七段提示词、审核、生成、编辑决定、导出与审片。
6. 隔离媒体与适配器验证、完整门禁、说明/交接/镜像与本地提交。

## 数据与执行契约

媒体在主进程管理的项目目录中，workspace 只存索引和结构化决定。手动导入仍由原系统选择器授权。
内容每次保存生成新版本，审核固定绑定输入摘要；旧版本、旧生成结果、人工验收绝不由模型重写。
故事必须由用户确认；输入变化后依赖审核失效。独立审核只传当前简报、内容和明确关联图像，不传制作自评。
所有付费请求先持久化逻辑任务和保守费用预留，再发请求。超时或断连的提交记为未知，不能自动再提交。
已取得 task ID 的任务只查询/下载；本地停止不声明供应商取消。最终费用未知时继续占用预留，账单可人工结算。
费用预估必须有用户填写的单价与来源；预留不代表供应商账单上界，生图和 Codex 费用另列。
模型和参数按用户选定的供应商能力配置，不把文章价格、模型 ID、色彩空间或构图比例当固定真理。

## 本地实现

- `video-schema.cjs`：可选schema1，完整内容历史、稳定镜头/设定ID、引用摘要、审核、执行与费用记录。
- `codex-studio-client.cjs`：官方stdio协议；独立兼容运行时，关闭工具宿主、文件读图、shell、MCP及桌面工具桥。
- `creation-image-adapter.cjs`：独立的手动图片适配器，自动生图明确不可用，不模拟图片成功。
- `video-manager.cjs`：故事/设定确认、镜头与邻镜依赖失效、隔离审核、原子费用预留、未知提交封锁、恢复与版本登记。
- `seedance-adapter.cjs`：官方创建/查询/下载，能力档案区分时长/声音/首尾帧规则；不写死模型ID/价格。
- `video-post.cjs`：受控FFmpeg剪辑、淡入淡出、音轨混合/替换、字幕、基础色彩调整、全量解码及抽帧拼图。
- 原生制作页按阶段渐进展示，支持构图色块、镜头排序拆分、设定记录、首尾帧比较、账本与独立全片抽样复核。

供应商DELETE兼具取消和删除语义，GET与DELETE间存在竞态；第一版不发送DELETE，
只能停止本地轮询，并明确引导用户控制台核查。未知提交仅在控制台确认未创建后，经系统弹窗释放预留。
范围为受约束制作流程；自动生图、供应商付费真测、原生细节恢复和专业时间线不在已验证能力内。

使用、数据目录及真实/模拟能力矩阵见[使用说明](../CREATION_VIDEO_GUIDE.md)。
