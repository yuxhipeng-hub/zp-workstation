# GitHub 发现 v1

入口为「资讯 → GitHub 发现」，默认周榜。复用现成公开数据，不租服务器、不部署采集任务、
不调用模型，不发送工作区、收藏或密钥。仅本地开发，不推送、合并或发布。

## 使用流程

1. 打开页面，先读取已保存的榜单，再按需检查网络。首次无缓存且离线时显示可重试的空状态。
2. 切换日榜、周榜、月榜。保留来源排序，展示项目介绍、语言、总 Star 和周期新增 Star。
3. 选择语言浏览当前榜单，不重新计算排名；不提供搜索。
4. 点击条目展开介绍，可以复制链接或在外部浏览器打开 GitHub。外部链接由主进程处理。
5. 点击书签收藏，在「我的收藏」离线阅读。介绍与指标为收藏时的快照，可取消收藏。
6. 刷新只请求来源已发布的最新快照；后台响应保留语言选择、键盘焦点与滚动位置。

## 留白与切换

- 沿用现有设计约定：页面内边距 24px/26px，窄窗口 20px/16px；条目在无内层边框的画布上对齐。
  不依赖只匹配直接子元素的标题样式，额外容器也必须保留内容与外框的距离。
- 本页桌面工具栏采用紧凑密度：视图/周期/刷新高 30px，语言触发按钮高 32px，文字 12px；
  页面外框留白保持不变，保留清晰的焦点环与选中状态。
- 视觉自检：去掉重复页内标题和第二层卡片边框；视图使用文字页签，周期使用分段控件，
  刷新为轻量图文按钮，列表使用横向分隔线。只在功能需要时使用浮层阴影。
- 语言筛选替换原生 select：32px 圆角触发按钮、10px 圆角浮层、6px 圆角选项，使用当前主题。
  Popover 顶层承载，绕开画布 overflow 裁切，按视口定位并限制高度；超长列表可滚动。
  支持选中勾、方向键、Home/End、Enter、Esc、Tab、点击外部关闭；选择或 Esc 后焦点回到触发按钮。
  后台刷新保留已打开的菜单与焦点，切页/切榜/滚动画布/窗口缩放时关闭。
- 删除搜索、重复介绍、底部技术说明、常驻缓存提示。仅保留一行来源、采集时间与条目数；
  加载或旧数据才显示简短状态，首次失败只显示一次空状态。
- 保持外层页面框架，局部更新标题、控件、状态与列表，加载期间保留列表高度；
  缩短内容后仍为当前滚动位置留足空间。切榜、刷新与异步回包不重建整个页面或重置滚动。

## 数据来源与网络

- 主来源：[GitStock 公开接口](https://gitstock.org/docs/trending)。
  固定 GET `/api/v1/github/trending?period=daily|weekly|monthly&description_lang=zh`；
  无需 Key，请求中文描述，来源未翻译时保留原文。
  项目身份、介绍、语言、指标、排名取对应字段；`captured_at` 是来源采集时间。
- 备用：[SnailDev/github-hot-hub](https://github.com/SnailDev/github-hot-hub)，MIT 开源。
  固定读取公开 README，按三个中文标题解析榜单，使用文件内带时区的更新时间。
  主来源失败或采集超过 6 小时才尝试备用；两者可用时比较采集时间，保留较新结果。
  备用保留原文，明确署名，不宣称两个来源是同一批快照。
- 每次请求最多 10 秒、响应最多 1 MiB。只访问固定 HTTPS 来源，拒绝重定向和渲染层指定 URL。
  桌面使用 Electron `net.fetch` 走系统网络配置，不自动修改代理、VPN、系统设置。
- 30 分钟内按需复用缓存；手动刷新可以重新检查。关闭电脑后第三方源是否更新取决于其运营，
  应用没有云端任务。持续停留页面时不启动定时轮询。
- `capturedAt` 为来源采集时间，`checkedAt` 为本机上次成功检查时间；采集超过 6 小时或读取失败
  会提示待更新。失败不刷新旧数据的时间，不用更早的来源覆盖较新的本地快照。
- 无租赁服务器需求不等于免 VPN 连通性保证。当前网络读取成功只证明当时可达；
  校园网、热点、关闭 VPN 后的长期稳定性仍需用户实网验收。
- 打开 GitHub 原站、下载项目仍受原站连通性影响。第一版不做代理、下载加速和 AI 解读。

## 存储与边界

- 网络缓存：用户目录内 `github-discovery-cache.json`，只保留三个周期的清洗后快照与成功检查时间。
  可恢复数据不进入工作区备份；串行化写入，临时文件原子替换。无效缓存丢弃并重新获取，
  无效/空/过大远端响应不覆盖已有缓存；磁盘写入失败仍展示已获取的结果并提示。
- 收藏：`workspace.json.githubFavorites`，默认空数组，最多 500 个。通过 WorkspaceStore
  显式备份后保存；写入失败回滚内存，沿用旧快照、完整备份和恢复路径。
  字段白名单保存仓库身份、说明、语言、指标与收藏时间，不接受来源提供的任意链接或未知字段。
- 仓库链接从通过校验的 `owner/repo` 生成 `https://github.com/owner/repo`；所有远端文字转义后显示。
  缺失指标为 null/暂无，不伪造 0；不会执行 Markdown、HTML、README 或模型指令。
- 三个固定 IPC：`github:snapshot`、`github:favorites`、`github:favorite-set`。
  校验周期、布尔值、项目名、字段白名单。收藏只能来自已加载的项目或已有收藏。
- 浏览器预览不请求网络，也不伪造榜单，提示在桌面应用查看真实数据。
