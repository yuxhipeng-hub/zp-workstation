# AI 资讯界面调整

按 [设计系统第 9 节](../DESIGN_SYSTEM.md#9-榜单与资讯列表已确认的视觉基准) 的已认可列表风格实现。
范围是 AI 资讯页与必要的渲染状态处理；保留 AIHOT 数据源、预加载 API 和今日页入口。

## 布局与文案

- 单一页面外框，内边距上下 24px / 左右 26px，窄窗口为 20px / 16px。
- 不重复顶栏标题，去掉常驻接口介绍；精选 / 热点 / 日报为 30px 文字页签，刷新为轻量图文按钮。
- 精选页保留分类、24 小时 / 7 天、搜索与分页；筛选用中性填充，时间范围用分段控件。
  搜索框高 32px，支持回车与点击图标提交；刷新从首页替换数据，加载更多才追加。
- 内容是带直线分隔的列表：标题 14px、元数据 11px、条目上下留白 18px。
  来源、时间、分类合并成行；去掉相关推荐里的重复元数据，不添加操作常识或技术小字。
- 保留摘要、原文标题、入选理由、复制、原文链接、相关推荐；热点点击展开综述与报道时间线，
  不自动展开第一条。日报保留导读、分类与条目。必要的来源署名、错误与加载反馈保持可读。

## 交互与失败状态

- 同页更新保留外层画布，局部替换控件与内容；加载时预留列表高度，保持滚动位置与键盘焦点。
- 刷新不丢失未提交的搜索草稿与选区；快速更换筛选时以最后一次请求为准，忽略旧回包。
- 更新失败保留已显示的精选/热点条目，显示简短“更新失败”；首次失败显示单一空状态，可直接刷新。
- 日报加载完成后更新当前视图；窄窗口筛选组允许换行，长标题与正文不撑破容器。

## 验证

- Electron E2E 使用隔离用户目录和模拟 IPC 响应，验证筛选、搜索、复制、分页、热点时间线、日报、
  离线恢复、重复刷新、过期回包、输入草稿与焦点，并逐帧核对延迟筛选期间的画布和滚动位置。
- 完整门禁通过：单测 226、E2E 45、覆盖率、构建、Lint、格式、类型和文档镜像。
  最后精简顶栏说明、统一悬停色并补齐跨页签高度预留后，单测 226、页面 E2E 3 与构建再次通过。
  深浅主题、窄窗口和浏览器中的精选、热点、日报与展开阅读已核对。
- 浏览器预览数据用于布局验证，不代表实时新闻或网络可用性；最终视觉待用户验收。
