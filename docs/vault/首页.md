## 和仓库的关系

真实来源永远是仓库文件，这个 vault 是"可读视图"。改完仓库文档跑一次同步命令，
这里的笔记就会重新生成；写在这里的内容会被覆盖，自己的笔记请另建文件。
详见 [[同步说明]]。

## 同步规则（每次都要做）

只要动了被镜像的仓库文件（`AGENTS.md`、`README.md`、`RELEASE.md`、`DESIGN.md`、
`docs/` 下的文档、`docs/vault/` 下的手写笔记），**任务收尾前必须跑一次同步**：

```powershell
npm run sync:vault
```

Windows 把文档目录重定向到别的盘时，先设 `ZP_WORKBENCH_VAULT` 或用 `--vault <路径>`
指定 vault 位置（脚本已经会自动读 Windows 注册表里的"文档"目录，本机解析到
`D:\Users\小zp\Documents\Obsidian Vault`，一般不用手填）。

想知道有没有漏同步，跑只读检查：

```powershell
npm run sync:vault:check
```

它会列出内容过期、缺失或多余笔记；`npm run verify` 已经把这一步接在最后。
